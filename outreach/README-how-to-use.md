# Cloud Kitchen Outreach Tracker — How to Use

File: `cloud-kitchen-outreach-tracker.csv` (open in Excel or Google Sheets)

## Column order (left → right = your pipeline flow)
1. **S.No** — serial number
2. **Date Added** — when you found the lead (YYYY-MM-DD)
3. **Business Name** — kitchen / brand name
4. **Business Type** — Cloud Kitchen, Central Kitchen, Cafe, etc.
5. **City / Area** — locality + city
6. **Contact Person** — name of who you spoke to
7. **Designation** — Kitchen Manager / Ops Manager / Owner
8. **Phone Number** — primary dialable number
9. **Alternate Phone** — backup number
10. **WhatsApp (Y/N)** — can you message them on WhatsApp
11. **Email** — if available
12. **Source** — Google Maps / Zomato / Swiggy / JustDial / IndiaMART
13. **Roles Needed** — Kitchen Helper, Cook, Dishwasher, Packer, Rider
14. **Headcount Needed** — how many people
15. **Status** — see list below
16. **Last Contacted** — date of your last call/message
17. **Next Follow-up** — date you should call again (key column!)
18. **Quoted / Order Value** — rate or monthly value
19. **Notes** — anything useful for the next call

## Status values (use exactly these — keeps the sheet sortable)
- **New** — added, not yet contacted
- **Contacted** — reached out, no decision yet
- **Interested** — wants a quote / more info
- **Negotiating** — discussing rates/terms
- **Order Placed** — converted ✅
- **Follow-up** — waiting, call again on Next Follow-up date
- **Not Interested** — closed, no
- **Wrong Number** — invalid contact

## Tips
- Sort by **Next Follow-up** each morning to see who to call today.
- Fill **Roles Needed** + **Headcount** during the first call — that's the order detail Switch needs.
- Rows 1–2 are demo examples — delete them once you start adding real leads.
- Reuse this same file for warehouses/3PL by changing **Business Type**.
